The tour advance, from your audience's taste.

Name the headliner, the cities or the country. Advance asks Qloo's taste graph the five questions a promoter answers by gut: where to play, who opens, which room, where fans go after the show, and which brands share the crowd.

Every line in the brief carries Qloo's affinity score and the exact request behind it.

How it works: a language model turns your sentence into a plan (headliner, cities, how big an opener may be), Qloo's Insights API answers each question for that headliner's audience, and the model writes up to three recommendations from a schema that lists only the names Qloo returned — it cannot recommend anything that is not in the brief. If the model is unavailable, a pattern planner and a template take over, and the trace says so. Built by KHLab on Qloo's Taste AI.
